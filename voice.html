VOICE
1. Voice কাকে বলে?

বাক্যের Subject কাজটি নিজে করে, নাকি Subject-এর ওপর কাজটি হয়ে — ক্রিয়ার এই প্রকাশভঙ্গিকেই Voice বা বাক্য বলে।

2. Voice-এর প্রকারভেদ
১. Active Voice

(কর্তৃবাচ্য)
Subject নিজে কাজ করে।

২. Passive Voice

(কর্মবাচ্য)
Subject-এর ওপর কাজটি হয়।

3. Active Voice

যে বাক্যে Subject নিজে কাজ করে, তাকে Active Voice বলে।

Structure :
Subject + Verb + Object

Example : Rahim reads a book.

4. Passive Voice

যে বাক্যে Subject-এর ওপর কাজটি ঘটিত হয়, তাকে Passive Voice বলে।

Structure :
Object + Auxiliary Verb + V³ + by + Subject

Example : A book is read by Rahim.

5. Subject, Verb ও Object চেনার সহজ উপায়
Rahim reads a book. ➔ কে কাজটি করে? (Subject = Rahim) ➔ কী কাজ করে? (Verb = reads) ➔ কী/কাকে? (Object = a book)
6. Subject-এর Objective form (by-এর পর ব্যবহৃত হয়)
SubjectIWeYouHeSheTheyIt
Objectivemeusyouhimherthemit

VOICE — IMPERATIVE
Active ➔ Passive
1. Affirmative (Do object)
Active : Do the work.
Passive : Let + Object + be + V³
➔ Let the work be done.
2. Negative (Do not object)
Active : Do not waste time.
Passive : Let not + Object + be + V³
➔ Let not time be wasted.
3. With "Let"
Active : Let me do the work.
Passive : Let + Object + be + V³ + by + Obj.
➔ Let the work be done by me.
4. Advice / Request (Please/Never)
Active : Always speak the truth.
Passive : Let + Object + be + always + V³
➔ Let the truth be always spoken.

VOICE — QUASI-PASSIVE
Quasi-Passive ➔ Passive
1. Quasi-Passive With Complement
Active structure : Subject + Verb + Adjective

Rule A: Sub + Auxiliary Verb + Adjective + when + it/they + is/are + V³
Rule B: Sub + Auxiliary Verb + V³ + Adjective
